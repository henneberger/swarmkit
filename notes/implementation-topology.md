# Topology and population-search implementation

All code is freshly written; no repository code was copied and no third-party source license is inherited. This is a tested mechanism library, not a claim to reproduce papers' full models, datasets, or benchmark results.

## Implemented

- `FullTopology`, `RingTopology`, `StarTopology`, `RandomTopology`, `LocalRadiusTopology`, and `HypergraphTopology` implement the shared `TopologyPolicy`. Recipients exclude inactive agents and self; random directed connectivity is cached per step; hyperedges broadcast to their union. Local radius uses actual Euclidean coordinates and rejects mismatched dimensions.
- `BernoulliDAGPolicy`: fixed-order independent Bernoulli edges; samples are cached until the next step. REINFORCE uses `(reward - baseline) * (sample - probability)` including absent edges. An EMA baseline reduces variance. Optional sampled-edge cost penalizes communication; an optional nuclear-norm subgradient of the expected adjacency matrix provides structural regularization. Magnitude pruning permanently removes a fraction of surviving edges. [GPTSwarm](https://arxiv.org/abs/2402.16823), [AgentPrune](https://arxiv.org/abs/2410.02506). Adaptations: fixed order, no prompt optimization, no complete spatial-temporal constrained training objective.
- `RoundDropoutTopology`: arbitrary-size, round-specific masks retain top-importance agents and remove low-score surviving edges. It does not permanently deactivate agents. Caller supplies learned importance. [AgentDropout](https://arxiv.org/abs/2503.18891). Adaptation: explicit node scores replace the paper's learned incident-connectivity estimator; intra/inter-round edge training is not reproduced.
- `DyLANSelection`: score-based contributor selection, backward weighted attribution over layers, strict greater-than-two-thirds consensus stop. Missing voters remain in the denominator; duplicates are rejected. [DyLAN](https://arxiv.org/abs/2310.02170). The ranker is supplied through its scores; agreement provides no correctness guarantee.
- `CapabilitySuccessRouter`: local capability-overlap plus empirical success EMA, optional exploration, visited-agent exclusion, and directed feedback. [AgentNet](https://arxiv.org/abs/2504.00587). Explicit adaptation: no LLM router, learned embedding model, task decomposition, or autonomous agent creation. Set required capabilities in `state.data[router.key + ':required']` for direct bus topology use, or call `route` explicitly.
- `ParticleSwarmSearch`: artifact-configured population; injected evaluation and mutation see current, personal best, global best, and bounded failure memories. All particles mutate against the same frozen global best per generation. Parent artifact ancestry persists, personal/global best are monotonic, and both maximizing and minimizing objectives penalize costs correctly. [SwarmAgentic](https://arxiv.org/abs/2506.15672). Adaptation: caller supplies language/symbolic/numeric mutation; no pretend universal numeric velocity over arbitrary configurations.

## State and integration

Every agent, artifact, feedback, decision, result, and swarm state uses `swarmkit.types`. Policies contain only immutable configuration; learned weights, masks, samples, and search histories reside in `SwarmState.data`. Use distinct keys for independent policies/searches. DAG population membership is fixed after initialization; active membership can change. Population search binds its state to one task id. It returns evaluated artifacts for the runtime to commit and never advances `state.step` itself.

`BernoulliDAGPolicy.update` updates each sampled graph once; a new step permits another sample. Prune after feedback, before the next evaluation. Its cached old graph remains stable within a round even after weights update. Particle callbacks must return fresh artifact ids and preserve particle author. No hosted model access, downloaded code execution, or paid inference is required.

Validation: focused pytest checks topology recipient invariants, spatial boundary errors, reproducible sampling, absent-edge gradients, learned rewarded communication, pruning monotonicity, nuclear-norm/empty-population boundaries, arbitrary-size round dropout, consensus thresholds and duplicate voters, routing success/visited constraints, population inheritance, bounded failure memory, invalid callbacks, task isolation, and minimization costs.
