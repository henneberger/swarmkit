# Swarm evolution: bounded source review

Reviewed 2026-09-09. Code inspected, not executed.

## SwarmAgentic

[Paper, arXiv:2506.15672v1](https://arxiv.org/abs/2506.15672v1), 18 June 2025; [code](https://github.com/YaoZ720/SwarmAgenticCode). Local `sources/papers/2506.15672/` and `repositories/YaoZ720__SwarmAgenticCode/`.

**Report-ready summary (132 words).** SwarmAgentic applies swarm optimization to the design of agent systems. Each particle is an entire candidate system—roles, responsibilities, policies and collaboration workflow—not one conversational worker. Task execution produces scores and failure diagnoses. Language-model updates combine lessons from failed adjustments, the particle’s personal best and the population’s global best, then edit the candidate’s roles and workflow. Thus its PSO is symbolic: “velocity” is a textual repair plan, not a numerical vector update. Tests across six task families report improvements over hand-designed and automated baselines; component ablations support failure-aware adaptation and structural changes. This is an optimizer-level swarm with centralized evaluation and global-best sharing. The resulting deployed system need not be a decentralized swarm. Its contribution is population-based discovery and transfer of useful organizational configurations; it does not establish spontaneous collective knowledge formation among persistent autonomous agents.

**Algorithm detail and code anchors.** Paper §§4.1–4.4, equations 4–7. Initialize diverse systems from task specification; evaluate; extract agent/structure flaws; compare present system with remembered personal/global best; diagnose previous unsuccessful changes; synthesize repair plan; apply role and workflow edits; regenerate executable forward function. In `natural_plan/_trip/pso.py:100`, fitness is computed; `:104` updates personal best; `:111` computes symbolic velocity with explicit personal/global reflections; `:135` analyzes failed adjustments; `:143` applies changes and `:147` regenerates forward code. `:189` performs centralized global-best selection. `prompt/velocity_update.py:7` begins the actual update template; its operation vocabulary includes adding/modifying/deleting roles, adding/removing/reordering workflow steps and modifying inputs/outputs. Numerical PSO notation in the paper is an analogy implemented through these language transformations, not evidence of standard continuous PSO dynamics or convergence guarantees.

**Evidence and limits.** Table 5 Creative Writing ablation: five particles/ten iterations score 8.8; without failure-driven adjustment 8.4; five particles/five iterations 6.9 versus one particle/five iterations 6.3. These isolate some contributions but changed particle counts also change compute, so do not interpret as equal-budget proof of social interaction benefit. Abstract's +261.8% TravelPlanner claim is relative to ADAS, not percentage-point accuracy improvement. Best-system transfer across backbones appears in Table 4; it establishes some organizational reuse, not general swarm emergent intelligence. Six benchmark families include structured mathematical reasoning; the paper does not exclusively evaluate open-ended discovery. Repository README identifies EMNLP 2025, while the locally reviewed arXiv artifact is explicitly v1.

## Virtual Lab Swarms: proposal only

[The AI Scientific Community: Agentic Virtual Lab Swarms, arXiv:2603.21344v1](https://arxiv.org/abs/2603.21344v1), 22 March 2026.

**Report-ready note (~80 words).** This short note proposes a nested swarm: each particle is a complete virtual laboratory. Labs influence others through citation-like votes; planning agents balance independent exploration against following successful labs, and anonymous reviewer agents assess results. Proposed mechanisms also seek to prevent dominant labs from eliminating diversity. It belongs in a clearly labeled future-directions paragraph: the abstract and conclusion say implementation is under development. There are no reported experiments establishing discovery quality, communication efficiency or advantages over isolated laboratories.
