# Knowledge and deliberation implementation

Owned files: `src/swarmkit/knowledge.py`, `src/swarmkit/deliberation.py`, `tests/test_knowledge.py`, `tests/test_deliberation.py`. Fresh implementations using canonical `swarmkit.types`; no copied upstream code and no new foundational data types. Source links appear in module/class documentation. These are runnable, scoped algorithmic adaptations; paper benchmark scores are not claimed.

## Public interfaces

- `EvidenceRegistry(evidence=())`: `add`, transactional `add_many`, `get`, `evidence`, `roots`, `scores(candidates)`, `independent_sources`. Immutable evidence snapshots with topologically admitted ancestry. Same-source reports and descendant retellings do not multiply source support. Multi-root derived claims divide confidence across roots; positive and negative support are accumulated separately with a per-root maximum. Independence depends on honest supplied source identifiers, not on counting voters or authenticating provenance cryptographically.
- `ArtifactStore(verifier, minimum_score=0)`: `admit`, `get`, `active`, `lineage`, `retire`. The verifier receives an isolated artifact and returns canonical `Feedback`. Requires `verified` and a finite score meeting threshold. Admission ignores an incoming verified flag; IDs cannot be overwritten; missing parents/self-parent cycles rejected. Copies on write/read protect mutable payload dictionaries. Retirement removes an artifact from adoption candidates while retaining its historical lineage.
- `PeerAdoption(store, evaluator, minimum_gain=0, memory_key='adopted_artifact')`: `adopt(agent,id,task)`, `audit(agent,task)`, `rollback(agent)`. Evaluator signature `(AgentState, Artifact | None, Task) -> Feedback`; `None` evaluates current baseline. Local gain must meet threshold. An uncommitted trial saves the previous memory reference; later failed or exceptional audit restores it. Successful audit commits the adoption. Inspired by Gensyn peer verification; this module installs an artifact reference, not source code or model weights.
- `DecayingMemory(half_life=4, threshold=.05)`: `write(artifact,step)`, `read(id,step)`, `refresh(id,agent_id,step)`, `available(step)`. Exponential expiry approximates minimal-culture decay. Reading does not refresh. Another peer can explicitly maintain a live record; expired items cannot be refreshed. Time cannot move backward. Refreshing does not invent independent corroboration or verified truth.
- `CulturalTransfer(store,evaluator,minimum_score=0).step(state,task)`: each receiver tests candidate artifacts locally, inherits its highest valid result and records ancestry in `agent.memory`; accepted artifacts are exposed in `state.artifacts`. Evaluator signature `(AgentState,Artifact,Task)->Feedback`. This is artifact-based generational transfer, not reproduction of RL policy inheritance.
- `ProcedureAbstraction(store,proposer,evaluator,minimum_score=0).discover(parent_ids,held_out,training_task_ids=())`: proposer consumes a tuple of admitted artifacts and returns a proposed `Artifact`; evaluator checks the artifact on each held-out `Task`. All tasks must pass; IDs must be distinct and disjoint from declared training IDs. Stores per-task scores and immutable parent lineage before independent admission verification. Trusted callbacks may execute a supplied Python procedure, but no text is interpreted or executed by the library.

## Deliberation interfaces

- `evidence_decision(agent,task,evidence) -> Decision`: transparent symbolic source-deduplicated scoring; deterministic task-order tie-break with zero confidence.
- `IndependentVoting(decide=evidence_decision).step(state,task)`: independent private-evidence decisions. Copied callback agent contexts clear inbox/memory/beliefs to exclude earlier peer answers. Independence here is information isolation, not independently trained models.
- `WeightedConsensus(weights=None,threshold=2/3,margin=0,stable_rounds=1,confidence_weighted=False,minimum_voters=1)`: `aggregate(decisions,task)` scores supplied ballots; `.step` scores fresh isolated default ballots. Duplicate voter IDs rejected; weights finite/nonnegative; tied or zero-weight votes cannot converge. Reports quorum share, margin, winner, per-candidate totals and stable-round count. `reset(task_id)` clears stopping history. Consensus is not a truth verifier.
- `ExchangeThenDecide(config=ExchangeConfig(),decide=evidence_decision,namespace='exchange').step(state,task)`: two exchange steps by default, then a decision pass. Each participant reveals up to two new relevant facts per round and supplies an objection to the publicly leading candidate. Provenance ancestors accompany disclosure; candidate scoring uses shared plus remaining private facts. No decisions during exchange. This is a symbolic HiddenBench Exchange-then-Decide adaptation, not mechanistic Reveal-All. Episode state is in `state.data`; active roster changes require explicit `reset(state,task_id)`.
- `CritiqueReviseDebate(critique,revise,decide=...,max_rounds=3,consensus=None,namespace='debate').step`: initial isolated proposals, followed by complete synchronous critique/revision rounds. Critic signature `(agent,tuple[Decision,...],task)->str`; reviser `(agent,own_decision,tuple[Message,...],task)->Decision`. Critics see the same preceding snapshot. All critiques exist before revision. A round cap sets done without falsely reporting convergence. `reset` clears an episode.

All protocol messages are returned un-routed in `AlgorithmResult`. The caller/runtime commits/routes them; methods never advance `state.step`. Lower-level stores are standalone application objects. Method instances with stopping history should be reset before reusing a task ID for a new episode.

## Validation

`.venv/bin/python -m pytest tests/test_knowledge.py tests/test_deliberation.py -q`: **16 passed**. Ruff checks on all four owned code/test files pass. Tests cover a three-to-one wrong initial majority overturned by two unique minority facts after exchange; source-copy inflation; multi-parent evidence; atomic cycle rejection; immutable artifact payloads; failed verification; retirement/ancestry; local adoption failure and rollback; maintained memory versus expiry; receiver-specific cultural transfer; held-out callable abstraction; isolated callback contexts; voting ties/quorum/stability; synchronous debate and nonconverged round caps.

Verification callbacks are trusted application code, not a sandbox. No provider calls, model inference, downloaded-code execution or paper experiments were performed.
